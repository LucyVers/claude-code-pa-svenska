# Ordlista för Claude Code på svenska

[← Tillbaka till kursplanen](KURSPLAN.md)

En samling ord och begrepp som dyker upp i kursen om Claude Code, i
bokstavsordning. Växer allt eftersom fler lektioner skrivs.

### Agentisk AI

AI som inte bara svarar på frågor, utan faktiskt utför uppgifter åt
dig: skapar filer, kör kommandon, testar resultat. Claude Code är ett
exempel.

### API-nyckel

En hemlig kod som ger ett program tillgång till en tjänst. Ska aldrig
delas i chatten eller sparas i klartext, håll den i en `.env`-fil
istället.

### CLAUDE.md

En fil där du sparar information om dig själv och hur du vill jobba,
så Claude kommer ihåg det mellan sessioner istället för att du
förklarar om och om igen.

### .env-fil

En fil för att spara känsliga uppgifter, som API-nycklar, separat från
din vanliga kod och chatt.

### Git

Ett gratis verktyg som sparar ögonblicksbilder av ditt arbete. Claude
Code använder det i bakgrunden, bland annat för att driva
ångra-knappen.

### Kontextfönster

Det Claude "kommer ihåg" under en session. Ju längre sessionen pågår,
desto fullare blir fönstret, och desto sämre presterar Claude när det
närmar sig gränsen.

### MCP

Kortform för Model Context Protocol, ett sätt för Claude att nå
riktiga verktyg utanför sig själv, som databaser eller andra tjänster,
istället för att bara svara i text.

### npm

Ett verktyg som laddar ner och installerar andra verktyg ett projekt
behöver. Du kör det sällan själv, Claude gör det oftast åt dig.

### Plan mode

Ett läge där Claude planerar innan den bygger något, istället för att
direkt börja skriva kod. Minskar risken för att arbetet går åt fel
håll.

### Prompt

Det du skriver till Claude, en instruktion eller fråga. Kan vara en
enda mening eller flera stycken.

### Sandlåda

En avgränsad yta där du och Claude formar en enskild sak tillsammans,
till skillnad från Claude Code som bygger på riktigt, med verkliga
filer och program.

### Session

En sammanhängande arbetsperiod med Claude, från att du öppnar appen
eller terminalen till att du avslutar eller kör `/clear`.

### Skills

Sparade, återanvändbara förmågor du kan ge Claude, så den inte behöver
läras upp från noll varje gång.

### Terminal

Den klassiska textbaserade skärmen för att styra en dator, ett av två
sätt att köra Claude Code.

### Tokens

De små textbitarna Claude bearbetar och "betalar" med. Din
kontextanvändning mäts i tokens.
