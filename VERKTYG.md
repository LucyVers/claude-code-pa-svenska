# Verktyg för Claude Code på svenska

[← Tillbaka till kursplanen](KURSPLAN.md)

Gratis eller nästan gratis verktyg värda att ha redo, i bokstavsordning.
Växer allt eftersom fler lektioner skrivs.

### GitHub

[github.com](https://github.com)

En gratis sajt som lagrar en kopia av dina projektfiler online, med en
fullständig historik av varje version som någonsin sparats. Claude
Code kan sköta kommandona åt dig, men det är värt att lära sig
grunderna själv också, så du inte står helt utan verktyg om AI:n
någon gång inte fungerar. Går något sönder går det alltid att gå tillbaka
till en tidigare version. Härifrån kan du också dela med andra eller
publicera en live-sajt.

### Vercel

[vercel.com](https://vercel.com)

En gratis tjänst som tar ditt projekt från GitHub och publicerar det
på en riktig webbadress vem som helst kan besöka. Kopplar du ihop dem
uppdateras din live-sajt automatiskt varje gång projektet sparas till
GitHub. Använd den när du vill att andra faktiskt ska kunna använda
det du byggt.

### VS Code

[code.visualstudio.com](https://code.visualstudio.com)

Ett gratis program från Microsoft där du skriver och redigerar filerna
som utgör ditt projekt. Det är också här du kan köra Claude Code och
se den jobba i realtid, öppna filer, ändra dem, skapa nya, på skärmen.
Använd det om du vill se vad som byggs istället för att bara bli
berättad att det blev byggt.
