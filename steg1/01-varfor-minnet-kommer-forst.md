# Varför Claude Code behöver komma ihåg dig

[← Tillbaka till kursplanen](../KURSPLAN.md)

*Del av kursen [Claude Code på svenska](../README.md) — Steg 1: Minne.*

Öppna en ny chatt i Claude Code och den vet ingenting om dig. Inte
ditt namn, inte vad du bygger, inte hur du gillar att jobba. Du börjar
om, varje gång.

Det går att fixa permanent, och det är därför det här steget kommer
före allt annat i kursen.

## Varför ordningen spelar roll

Du hade kunnat hoppa förbi det här och gå rakt på att bygga en
webbsida istället. Det går bra, men du förklarar din ton, ditt sätt
att jobba och vad "klart" betyder för dig på nytt varje gång du öppnar
Claude Code. Sätter du upp minnet först slipper du betala den
kostnaden om och om igen, och varje lektion efter den här går
snabbare eftersom grundarbetet redan är gjort.

## Det du gör i den här lektionen

Du pratar med Claude i skrivbordsappen, ingen fil, ingen terminal,
tills den vet vem du är, vad du håller på med och hur du vill jobba.
Det tar några minuter, och du gör det en gång.

**Nästa:** [Importera ditt minne från ChatGPT eller Gemini till Claude Code](02-importera-minne.md)

Claude Code utvecklas snabbt. Det som stämmer idag kan vara förändrat
om några månader. Jag uppdaterar allt eftersom jag hinner och hittar
ny information.
